# Workspace overview

The active Astro site is in `dark-disk/`.

Older or starter materials are retained under `archive/` without modification:

- `legacy-cafe-static-site/` — the original static HTML/SCSS site and its assets.
- `starter-files/` — unused HTML and Astro starter files.

To work on the current site:

```powershell
Set-Location dark-disk
npm run dev
```
